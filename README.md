# To-Do List Manager (Python)

## 📌 Project Description
This project is a simple To-Do List Manager developed in Python. It allows users to manage daily tasks using a command-line interface.

## ⚙️ Features
- Add tasks
- Delete tasks
- Show all tasks
- Mark tasks as completed
- Set task priority (low, medium, high)
- Save tasks to CSV file
- Load tasks from CSV file
- Export tasks summary to TXT file

## 🧠 OOP Design
- `Task` class: Represents a single task
- `ToDoManager` class: Manages all tasks
- Uses encapsulation and class-based structure

## 🔧 Modules
- `models.py` → Task class
- `manager.py` → Main logic and task management
- `file_handler.py` → File saving and loading (CSV & TXT)
- `main.py` → User interface (menu system)

## 🧪 Testing
Unit tests are implemented using Python's unittest module.
